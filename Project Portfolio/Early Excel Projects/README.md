# Early Excel Projects
This folder contains a collection of early spreadsheet projects created while I was developing my analytical, problem-solving, and data-organizing skills. These workbooks were built to automate repetitive tasks, structure information, support decision-making, and explore how spreadsheets can be used as practical tools beyond basic calculations. They reflect my early interest in using data to solve real-world problems and improve efficiency in both professional and personal contexts.

## Timekontroll 2014 v2.xlsx
This spreadsheet was developed to streamline employee time registration and improve the review process for a business setting. The original workflow involved a large amount of manual input and administrative checking, which made the process slow and error-prone. I redesigned the workbook using formulas, structured layout, and validation logic to automate recurring calculations and reduce the monthly review effort from roughly 10–20 hours to 2–4 hours. The project demonstrates early experience with spreadsheet automation, data validation, and workflow optimization.

## Turnus Calc 12 ukers - Uten mangler - testing for duplicates (2).xlsx
This workbook was created as a scheduling and compliance tool for evaluating work rosters against labor rules and agreements. The purpose of the sheet was to convert schedules into a consistent format, identify missing shifts, and flag potential violations in hours worked over a 12-week period. It was designed to handle up to 26 employees and highlight irregular patterns in a clear and structured way. This project reflects my interest in using spreadsheets for operational analysis, rule-based validation, and practical decision support.

## Terraforming Mars Solo Game.xlsx
This spreadsheet was built as a personal solo-game planning tool for Terraforming Mars. It was designed to track resources, production, card effects, and progression during a single-player session so that multiple games could be tested efficiently. The workbook helped organize strategic decisions into a structured format and made it easier to compare different tactics across runs. It represents an early example of using spreadsheets to model game systems and support strategic planning.

## Armor finder - Mortal Online 2.xlsx
This workbook was created as a database-style comparison tool for armor and equipment in Mortal Online 2. It was designed to organize item attributes in a searchable and comparable format, making it easier to evaluate different combinations and identify the strongest options for a given build. The project reflects an early effort to apply spreadsheet logic to data-heavy comparison tasks and optimize decision-making using structured information.

## Best_bow_finder2 (version 1).xlsb.xlsx
This file was created as a custom comparison tool for evaluating bows and related equipment in a game context. It organized performance values and stat differences in a simple, structured layout so that the strongest choices could be assessed quickly. The workbook demonstrates an early approach to spreadsheet-based analysis, comparison logic, and practical model-building for game-related data.

## Item og Quest oversikt - Escape from Tarkov.xlsx
This spreadsheet was built as an overview tool for items and quest-related information in Escape from Tarkov. It was designed to organize key references into a manageable format, making it easier to review item usage, progression relevance, and preparation needs without relying on scattered notes. The workbook reflects an early attempt to create a structured personal reference database using Excel.

## itemQuestTTK - Tarkov.xlsx
This file was developed as a companion tracking sheet for items and quests in Escape from Tarkov. It helped organize gameplay information in a compact table-based format so that progression and item relevance could be reviewed quickly. The workbook demonstrates how spreadsheet tools can be used to turn informal game knowledge into a searchable and maintainable reference system.

## Notes
These projects represent an early stage in my work with data, automation, and structured problem-solving. They are not intended as final production systems, but they reflect a strong practical interest in using spreadsheets as analytical tools and a foundation for later software-focused work.
